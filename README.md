# NexScript

A free, modern Roblox script discovery tool. Search, browse, and copy scripts for your favorite games.

[**Live Demo**](https://nexscript-official.vercel.app) · [**Discord**](https://discord.gg/nnaHS7xmJU)

---

## ✨ Features

- 🔍 **Search** — Find scripts by keyword
- 🔥 **Trending** — Popular scripts right now
- 🆕 **Newest** — Latest scripts
- 👁️ **Most Viewed** — Top viewed
- ⭐ **Top Rated** — Highest liked
- ✅ **Verified** · 🔓 **Keyless** · 🌐 **Universal** — Filter by type
- ❤️ **Favorites** — Bookmark & sync across devices
- 💬 **Global Chat** — Talk with other users
- 📺 **Shorts** — YouTube video feed
- 📤 **Upload** — Share your own scripts
- 🌙 **Modern dark theme** — Midnight blue design

---

## 🛠️ Built With

- React 18 · Tailwind CSS
- Supabase (auth & database)
- Vercel (hosting & serverless)
- Adsterra (ads)
